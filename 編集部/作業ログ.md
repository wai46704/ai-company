# 📒 作業ログ（いつ何をしたか）

**このファイルを見れば「いつ何をしたか」が分かります。** 朝会の日も、朝会なしで直接作業した日も、すべてここに残します。

## 書き方のルール（編集長）
- **新しい日を一番上に足す**（降順。古い日を下に積む。※ `データ/SNS分析ログ.md` は途中で並び順が壊れたので、その轍を踏まないこと）
- **1日あたり数行**。何をしたか（結果）と、成果物がどこにあるか（リンク）だけ書く。議論の経緯は詳細ファイルに任せる
- **書くタイミング**：作業が一区切りしたら（特に記事の公開・サイトの変更・push のあと）。朝会の有無に関わらず書く
- 朝会をした日は最後に `朝会あり → [日報](日報/YYYY-MM-DD.md)` を添える
- 迷ったら書く。書かない日ができると、あとから追えなくなる
