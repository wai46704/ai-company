## 1. ⚠️ 設計上いちばん大きな論点（編集長へ）

記事案（ミナト案）は **「これまで実際に選んできた返礼品を振り返り、複数の返礼品をレビューする」** という構想です。
しかし既存記事の記述は **「今年が初めて」「1自治体のみ」「トイレットペーパー1点」**。

つまり **記事案が前提にしている『複数の返礼品の使用感レビュー』は、現時点の記述と食い違います。**
記事案にある「量が多すぎて消費しきれなかった」「配送タイミングが読めなかった」も、社長は**一言も語っていません**（ミナトの想定例です）。

→ したがってこの加筆は、**「複数返礼品のレビュー記事」ではなく「1点を選んで実際に使ってみた結果と、手続きの顛末」** に企画を寄せるのが自然です。
→ 前提が変わっていないか（=今も1自治体・1点のままか）を、**質問Q1で最初に確認**します。ここがNoなら設計を組み直します。

## 2. 加筆の入れ場所と構成（枠だけ）

既存の見出し構成は次の通りです。**この順序とトーンは崩しません。**

```
1. 限度額を超えるとどうなる？基本の仕組み
2. 【年収・家族構成別】あなたの限度額はいくら？
3. 計算を狂わせる「4つの落とし穴」
4. 後悔しない返礼品の選び方   ← 鉄則1の直後に既存の体験談ブロック
5. まとめ
（PR広告 → 免責文 → あわせて読みたい）
```

### 加筆方針：セクション4と5のあいだに、新セクションを1つ挿入する

```
4. 後悔しない返礼品の選び方
5. ★新設★ 実際にやってみて分かったこと（仮）   ← ここに加筆
6. まとめ（現5を繰り下げ）
```

**理由**：既存の体験談ブロック（L109）は「なぜトイレットペーパーを選んだか」という**選ぶ前の話**。今回の体験談は**選んだ後の話**（届いた後・手続き）なので、時系列的に鉄則1〜3を読み終えた後に置くのが自然です。既存ブロックを膨らませると引用囲みが長大になり読みにくくなるため、独立セクションにします。

### 各枠の設計（★本文は社長ヒアリング後に執筆）

#### 枠A：ポータルサイト選びと、申し込みで迷ったところ
- 見出し案：`### 申し込むまでに、いちばん迷ったこと`
- 想定字数：**約200〜250字**
- 意図：制度は分かったが実行に移せない読者の背中を押す。既存L63（シミュレーター）の直後の話として時系列がつながる。
- 中身：**空欄**（Q2で取得）
- `<!-- 体験談候補: ポータルサイト選び・申し込み手順で社長が迷った点。Q2の回答が入る -->`

#### 枠B：届いてみて、どうだったか
- 見出し案：`### 届いてみて分かった「置き場所」の話`（※中身次第で見出しを変える）
- 想定字数：**約250〜300字**
- 意図：記事案の核である「リアルな使用感」。日用品を選ぶ読者がいちばん知りたいのは量と保管。
- 中身：**空欄**（Q3で取得）
- `<!-- 体験談候補: 返礼品が届いた時期・量・保管の実感。Q3の回答が入る。※社長が語っていない量や日数を推測で書かないこと -->`

#### 枠C：想定と違ったこと（あれば）
- 見出し案：`### 想定と違ったのは、この一点`
- 想定字数：**約200字**
- 意図：失敗談＝差別化の要。ただし**無理に作らない**。Q4が「特になし」なら**この枠ごと削除**し、枠Bに吸収する。
- 中身：**空欄**（Q4で取得）
- `<!-- 体験談候補: 想定外だった点。「特になし」ならこのセクションごと削除する -->`

#### 枠D：ワンストップ特例の書類、その後（**既存記述の続報**）
- 見出し案：`### ワンストップ特例の書類、その後どうなったか`
- 想定字数：**約250〜300字**
- 意図：既存L113で「まだ返送できていない」と書いたまま止まっている。**読者が続きを知りたい唯一の未回収の伏線**。ここを回収できると記事の誠実さが増す。
- 注意：**既存L113の本文も、Q5の回答に合わせて書き換えが必要**（返送済みなら「まだ返送できていません」は事実と食い違う）。加筆と同時に既存文の時制を直すこと。
- 中身：**空欄**（Q5で取得）
- `<!-- 体験談候補: ワンストップ特例書類のその後。既存L113の記述もあわせて更新する -->`

#### 枠E：来年はこうする
- 見出し案：`### 来年、変えようと思っていること`
- 想定字数：**約150〜200字**
- 意図：セクション6（まとめ）への橋渡し。
- 注意：既存L111に「**来年も、この選び方は変えないつもりです**」とある。ここと矛盾させないこと。**「選び方は変えない／別のことを変える」**のか、**「考えが変わった」**のかをQ6で確認する。
- 中身：**空欄**（Q6で取得）
- `<!-- 体験談候補: 来年の方針。既存L111「選び方は変えないつもり」との整合を必ず確認 -->`

### 字数の見込み

| 項目 | 字数 |

## 4. 社長への質問案（選択式・全7問／自由記述なし）

### 🔴 優先1｜Q1. 前提の確認：ふるさと納税の実績は、今も「1自治体・トイレットペーパー1点」のままですか？

- D. その他

> ※ここがB・Cだと、加筆の構成そのものを組み直します。**最初に確定させたい1問です。**

### 🔴 優先2｜Q2. 申し込むまでに、いちばん時間がかかった／迷ったのはどれですか？（複数選択可）

- A. どのポータルサイト（さとふる・楽天など）を使うか

- C. 返礼品を何にするか
- D. 寄付する自治体をどこにするか
- E. 支払い方法や名義の設定
- F. 特に迷わず、すんなり終わった
- G. その他

### 🔴 優先3｜Q3. 返礼品（トイレットペーパー）が届いたときの実感に、いちばん近いものは？（複数選択可）

- B. 量はちょうどよかった
- C. 思っていたより少なかった
- D. 届く時期が想定と違った（早すぎた／遅すぎた）
- E. 品質・使い心地が想像と違った（良い方向）
- F. 品質・使い心地が想像と違った（悪い方向）
- G. まだ届いていない
- H. その他

### Q4. 「これは想定外だった」と感じたことはありますか？

- A. 特にない（順調だった）
- B. 届くまでの期間
- C. 梱包の大きさ・受け取りの手間
- D. サイトの手続きの分かりにくさ
- E. 自治体からの書類・連絡まわり
- F. その他

> ※Aなら、加筆の「枠C（想定と違ったこと）」は**作らず削除**します。

### Q5. ワンストップ特例の申請書類は、その後どうなりましたか？

- A. 返送済み（無事に完了した）
- B. まだ返送していない
- C. 返送しようとしたが、書き方や添付書類で詰まった
- D. ワンストップ特例をやめて、確定申告する方針に変えた
- E. その他

> ※既存記事に「まだ返送できていません」と書いてあります。**A・C・Dの場合はその既存の一文も書き換えます。**

### Q6. 来年について。既存記事には「来年も選び方は変えないつもり」と書いてあります。今のお気持ちは？

- A. 変わらない。来年も生活必需品を1点

- A. 初めてでも意外と簡単だった、という安心感
