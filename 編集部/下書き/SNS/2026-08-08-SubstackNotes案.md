## 1. 素材の選定（6つのうち5つ）

### 採用した5本と、その理由

「ゼロから見つけてもらう」＝ わたしを知らない人が、1行目を見て手を止めるか。判断軸は**①冒頭で状況が立ち上がるか ②常識に逆らうか ③体験の当事者性があるか**の3つです。

| # | 素材 | 採用理由（なぜ「見つけてもらう」のに向くか） |
|---|---|---|
| 1 | 標的型メール訓練 | **「見抜いたのではなく、たまたま照合できるものが手元にあっただけ」が強い逆説。** セキュリティの話は普通「詳しい人に聞け」で終わるが、この体験は**聞かれた側にも分からない**という逆を突く。専門知識ゼロでも情景が分かる |
| 2 | 親と詐欺の話をしたことがない | **「避けていたのではなく、話題にしないまま来た」という自覚が生々しい。** 親が健在な読者のほぼ全員に刺さる普遍性がありながら、「2か月に一度、父の眼科に付き添う」という具体で立ち上がる。**コメントが最も付きやすい** |
| 3 | 昨年も転職に応募した／面接に至らなかった | **失敗をそのまま出せる唯一の素材。** Notesで効くのが「取り繕わない弱さ」。世の中の転職コンテンツが成功談ばかりの中、**うまくいかなかった話**は逆張りとして立つ |
| 4 | サブスクは基本月払い | **「年払いのほうが得」という定説にまっすぐ逆らう。** 理由が「やめたいときにやめられるから」と一言で言い切れて、読者が自分の契約を即座に思い出す。**軽くて、いちばん気楽にコメントできる** |
| 5 | 持病があっても有給は2年に1度の検査くらい | **「難病＝長期休業」という思い込みを、当事者の実データで外す。** 当事者にしか書けない話で、代替不能。ただし扱いは慎重に（下記） |

### 見送った1本

**Emergency Kitを紙にしなかった（デジタル終活）** を落としました。

理由は、**この5本の中で唯一「前提知識」を要求するから**です。1PasswordのEmergency Kitが何かを知らない読者は、1行目で状況を掴めません。Notesは1行目で「read more」を押すか決まる場なので、前提説明から入る素材はここでは不利です。

内容自体は良い素材（「穴があると分かっていて、まだ伝えていない」という未完了の正直さ）なので、**Xの告知文か、Notesに慣れた後の2巡目に回す**ことを提案します。

## 3. 運用メモ（社長・編集長へ）

### ⚠️ Note 5 にリンクを入れなかった理由

Note 5は健康の話です。**共感を集めた直後にブログへ誘導すると、「病気の話を集客に使った」ように見えるリスク**があります。数字より、この場での信用を優先しました。もし記事へ送りたい場合は、Noteを出して反応が付いた後、**コメント欄で聞かれたら答える形**が自然だと思います。

### リンクを1本だけにした理由

調べた範囲で「直接的な宣伝は2週に1回まで」という助言がありました（[出典](https://thewritinglonggame.substack.com/p/i-analyzed-1000-substack-notes-heres)）。5本すべてに記事URLを付けると、初見の読者には**告知アカウント**に見えます。購読者1人の今、最初に作るべきは告知の導線ではなく「この人の話は読める」という印象なので、リンクは Note 1 の1本に絞りました。

Note 1を選んだのは、話が「聞かれた側も材料がなければ分からない」という**未解決で終わる**ため、記事が自然な受け皿になるからです。

### 投稿の順番（提案）

1日1本、この順を提案します。**軽い→重い**ではなく、**入りやすい話で顔を覚えてもらってから、当事者性の高い話を出す**設計です。

2. **Note 1（標的型メール訓練）** — 逆説が立っている。唯一のリンク付き
3. **Note 2（親と詐欺の話）** — 共感の幅が最大。コメントが期待できる
4. **Note 3（転職の失敗）** — 弱さを出す。3本出した後のほうが効く
5. **Note 5（難病と有給）** — いちばん当事者性が高い。最後に

### 【投稿状況・2026-08-11 編集長記録】

## 4. ご質問への回答：X向けとNotes向けは、何を変えるべきか

**結論：同じ原稿を流用してはいけません。別々に書くべきです。** 理由は「長さが違う」以上に、**評価されるものが違う**からです。

### 決定的な差

| | X | Substack Notes |
|---|---|---|
| 何が評価されるか | インプレッション（表示回数） | **コメントとリスタック**（いいねは軽い） |
| 適正な長さ | 140字 | **250ワード目安**（日本語での適正は不明。本案は実測280〜380字） |
| リンク | 貼っても自然 | **貼りすぎると宣伝アカウント扱い**（2週に1回まで） |
| ハッシュタグ | 2個まで（既存ルール） | 根拠が確認できず、使わない |
| 読者との距離 | 流し見。1秒で判断される | **1行目で「read more」を押すかが決まる**＝ 続きを読む意思が要る |
| 効くネタ | AIニュース3行まとめ・具体的な金額 | **体験・弱さ・常識への逆張り** |

### 具体的に何を変えるか

**1. Xは「情報」、Notesは「人」。**
Xで最も伸びた勝ちパターンはAIニュース3行まとめ（288インプレ）でした。これは**情報の速さと要約の価値**で獲った数字です。一方Notesで評価されるのは体験と弱さ。**AIニュース3行まとめをNotesに流用しても、たぶん伸びません。** 逆に「面接に至らなかった」はXの140字では削れて痩せます。**ネタ自体を分けるべきです。**

**2. Xは切り詰める、Notesは呼吸させる。**
Xの140字は情報密度を上げる方向に働きます。Notesは逆で、**1段落3行・空行必須**。同じ内容でもNotesでは「ところが」「それだけです」のような、間を作る言葉が要ります。**Xの原稿をNotesに貼ると、密度が高すぎて息が詰まります。**

**3. 問いかけは、どちらも効くが数が違う。**
Threadsで返信を取れた「共感の入口→末尾を問いかけ」は**Notesでも有効**です（コメントが評価される仕様なので、むしろXより効くはず）。ただしNotesは**1本につき問いかけ1つまで**。Xで複数の投げかけを入れていた型は、そのままでは持ち込めません。

**4. 唯一そのまま使えるのは「素材」。**
文章は流用できませんが、**社長の実体験という素材は両方で使えます。** 同じ「サブスクは月払い」でも、Xは「年払いの割引より、やめやすさを取っています。あなたはどっち派？」の1行に凝縮、Notesは判断の経緯まで書く。**素材は共有、原稿は別。** これが今後の運用設計として提案する形です。

### 運用上のリスク（先にお伝えします）

Notesは**Substackのメルマガ本体と同じアカウントで動きます。** Notesでの振る舞いがそのまま購読の入口の印象になるので、Xより丁寧に運用する必要があります。Threadsを失った直後なので、**量を出して当てにいく運用は、ここではしないほうがいい**と考えています。1日1本、5日で様子を見て、コメントが付くかどうかで型を調整させてください。
