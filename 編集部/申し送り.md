# 📋 申し送り（社長への質問・回答の引き継ぎ台帳）

このファイルは**セッションを跨いで「社長への質問と回答」を引き継ぐための唯一の台帳**です。
朝会（`/asakai`）は開始時にまずここを読みます。セッション開始フックでも `未回答` が自動表示されます。

## 運用ルール（編集長・必須）
1. **朝会/作業の開始時にここを最初に読む。** `回答済み` にある質問は**二度と社長に聞かない**。
2. 社長へ新しい質問を投げたら、セッションを終える前に必ず `🔴 未回答` に1行足す（チャットで言いっぱなしにしない）。
3. 社長が答えたら**その場で** `未回答→🟢 回答済み` へ移し、**社長の回答原文**・日付・反映先を書く。詳しい取材内容は従来どおり `編集部/データ/ヒアリング回答/<slug>.md` に保存し、ここからリンクする。
4. その質問が下書き本文のコメントとして残っていたら、回答を反映すると同時に**本文コメントを削除**する。
5. 体験談候補・確認事項は**記事本文に埋め込まない**。ここ（未回答）と校閲メモに集約する（本文に残すのは出典コメントだけ）。
