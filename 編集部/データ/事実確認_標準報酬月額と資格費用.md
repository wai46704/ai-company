# A. 標準報酬月額を給与明細から逆算する方法

## A-0. 前提：そもそも逆算せずに調べる正攻法がある（記事に必ず入れてください）

逆算は「決定通知書が手元にない人がその場でできる方法」ですが、**正確に知りたいなら公式に確認できる手段が2つあります**。逆算だけを勧めると不正確な記事になるので、必ず併記してください。

1. **ねんきんネット**（日本年金機構）
   - 各月の厚生年金保険の**標準報酬月額・標準賞与額を月単位で確認できる**
   - 「年金記録を確認する」→「一覧で年金記録を確認する」から表示
   - 出典: [「ねんきんネット」による年金記録の確認｜日本年金機構](https://www.nenkin.go.jp/n_net/utilization/confirmation.html)（確認日2026-08-08）
2. **年金事務所の窓口**で「被保険者記録照会回答票」を取得する（本人確認書類が必要）

→ 記事の構成としては「①まず給与明細で逆算してあたりをつける → ②ねんきんネットで答え合わせ」が、正確かつ読者の手が動く流れになります。

## A-1. 厚生年金保険料からの逆算式

### 計算式

```
厚生年金保険料（全額）  = 標準報酬月額 × 18.3%
厚生年金保険料（本人負担）= 標準報酬月額 × 9.15%   ← 労使折半

（逆算）
標準報酬月額 = 給与明細の「厚生年金保険料」 ÷ 0.0915
```

- 保険料は**事業主と被保険者で半分ずつ負担（労使折半）**
  - 出典: [厚生年金保険の保険料｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)（確認日2026-08-08）
- 給与明細に載っている「厚生年金保険料」は**本人負担分（＝折半後）**です。ここを全額と勘違いすると倍の標準報酬月額が出てしまいます

### 具体例（協会けんぽ 東京都・令和8年度の保険料額表で検算済み）

給与明細の厚生年金保険料が **31,110円** だった場合：

```
31,110 ÷ 0.0915 = 340,000
→ 標準報酬月額 340,000円
```

公式の保険料額表でも一致します。

| 項目 | 値 |
|---|---|
| 標準報酬月額 | 340,000円 |
| 報酬月額の範囲 | 330,000円以上 〜 350,000円未満 |
| 厚生年金保険の等級 | **21等級**（全32等級） |
| 健康保険の等級 | **24等級**（全50等級）※番号が違う点に注目 |
| 厚生年金保険料 全額 | 62,220円 |
| 厚生年金保険料 折半額（本人負担） | **31,110円** |
| 健康保険料 全額 / 折半額（東京・R8） | 33,490円 / 16,745円 |
| 健康保険料（介護保険第2号該当者）全額 / 折半額 | 38,998円 / 19,499円 |
| 子ども・子育て支援金 全額 / 折半額 | 782円 / 391円 |

- 出典: [令和8年3月分（4月納付分）からの健康保険・厚生年金保険の保険料額表（東京都）｜協会けんぽ](https://www.kyoukaikenpo.or.jp/assets/R8_13tokyo.pdf)（PDF本体から実データを抽出・確認、確認日2026-08-08）

### 重要：厚生年金は1円未満の端数が出ない

厚生年金の標準報酬月額は**すべて「偶数千円」**（88,000／98,000／104,000…340,000…650,000）で、これに9.15%を掛けると必ず整数円になります。
つまり**厚生年金保険料からの逆算は端数で狂いません**。ここが逆算の主役に厚生年金を選ぶ最大の理由です。

（健康保険料・介護保険料は1円未満の端数が出るため、50銭以下切り捨て・50銭超切り上げの処理が入る＝逆算がズレます。根拠は「通貨の単位及び貨幣の発行等に関する法律」。出典: [保険料の計算方法について｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/nofu/20121026.html) 確認日2026-08-08）

## A-2. 2026年度の厚生年金保険料率と、固定されているか

| 項目 | 内容 |
|---|---|
| 厚生年金保険料率（2026年度／令和8年度） | **18.300%**（本人負担 9.15%） |
| 固定されているか | **固定されている。** 平成16年（2004年）改正で段階的に引き上げられ、**平成29年（2017年）9月を最後に引上げ終了**、以後18.3%で固定 |

- 出典: [厚生年金保険の保険料｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)（確認日2026-08-08）
- 上記の令和8年度保険料額表PDFのヘッダーにも「厚生年金保険料率：平成29年9月分～適用 18.300%」と明記

### ⚠️ ただし「上限」は2027年9月から動きます（記事に一言入れる価値あり）

2025年（令和7年）成立の年金制度改正法により、**厚生年金の標準報酬月額の上限が段階的に引き上げ**られます。

| 時期 | 上限 | 等級 |
|---|---|---|
| 現在（2026年8月時点） | 650,000円 | 32等級 |
| 2027年9月〜 | 680,000円 | 33等級新設 |
| 2028年9月〜 | 710,000円 | 34等級新設 |
| 2029年9月〜 | 750,000円 | 35等級新設 |

- **料率（18.3%）は変わりません。変わるのは上限＝等級の刻みです**（32等級 → 35等級へ）
- 根拠法: 「社会経済の変化を踏まえた年金制度の機能強化のための国民年金法等の一部を改正する等の法律」**2025年（令和7年）6月13日成立・6月20日公布**
- 影響を受けるのは**賞与を除く報酬月額が66.5万円以上**の人（第一段階時点）
- 出典: [【2027年9月開始】厚生年金の標準報酬月額の上限引き上げ｜社労士ナビ](https://www.chukidan.jp/navi/column/insurance/13503/) ／ [厚生年金の標準報酬月額、上限75万円へ令和9年から段階的に引上げ｜SATO PORTAL](https://www.sato-group-sr.jp/portal/archives/3818) ／ [厚生年金の標準報酬月額上限引き上げとは？｜東証マネ部！](https://money-bu-jpx.com/news/article067948/)（いずれも確認日2026-08-08）
- ⚠️ 成立・公布は複数の社労士事務所サイトで一致しており確度は高いですが、**厚労省の一次資料そのものは未確認**です。記事に書く場合は「2025年成立の年金制度改正法により、2027年9月から段階的に引き上げられる**予定**」と**予定であることを明示**してください

## A-3. 健康保険料から逆算する場合との違い

**編集長の理解（厚生年金のほうが逆算しやすい）は正しいです。** 理由は3つあり、記事ではこの3点を並べると説得力が出ます。

### 理由1: 健康保険料率は都道府県ごとに違う（協会けんぽの場合）

- 令和8年度の協会けんぽ 平均保険料率: **9.9%**
- 東京都: 令和7年度 9.91% → **令和8年度 9.85%**（引き下げ）
- 最も高い: **佐賀県 10.55%** ／ 最も低い: **新潟県 9.21%**（いずれも協会けんぽの都道府県別 保険料額表PDFの本体から実測して確認済み）
  - 同じ標準報酬月額340,000円でも、健康保険料の本人負担は**東京16,745円／佐賀17,935円／新潟15,657円**と1か月で2,000円以上の差が出ます（各料率×340,000÷2で算出）
- 出典: [令和8年度の協会けんぽの保険料率は3月分（4月納付分）から改定されます｜協会けんぽ](https://www.kyoukaikenpo.or.jp/about/business/insurance_rate/rate_prefectures/r08/index.html) ／ [令和8年度 保険料額表（新潟県）](https://www.kyoukaikenpo.or.jp/assets/R8_15niigata.pdf) ／ [同（佐賀県）](https://www.kyoukaikenpo.or.jp/assets/R8_41saga.pdf)（確認日2026-08-08）

### 理由2: 健保組合なら料率はさらにバラバラ

勤務先が**健康保険組合**（協会けんぽではない）の場合、料率も労使の負担割合も組合ごとに独自です。**折半とは限りません**（会社が多く負担する組合が珍しくない）。この場合、健康保険料からの逆算は原理的にできません。
一方、厚生年金は**全国一律18.3%・完全折半**なので、勤務先がどこでも同じ式が使えます。

### 理由3: 2026年度から健康保険料に「別モノ」が2つ乗る

健康保険料の欄から逆算しようとすると、以下が混ざります。

| 上乗せ | 率（2026年度） | 対象 |
|---|---|---|
| 介護保険料率 | **1.62%**（全国一律） | 40歳〜64歳（介護保険第2号被保険者）のみ |
| 子ども・子育て支援金 | **0.23%**（全国一律） | 健康保険の被保険者全員（2026年4月分から新設） |

- 協会けんぽ東京の令和8年度表では、介護保険第2号該当者の率は「9.85% + 1.62% = **11.47%**」として表示されています（PDFから確認）
- 子ども・子育て支援金は**2026年4月から始まったばかりの新制度**。労使折半で、翌月控除の会社なら**5月支給の給与から**天引きが始まっています
- 出典: [令和8年度の協会けんぽの保険料率｜協会けんぽ](https://www.kyoukaikenpo.or.jp/about/business/insurance_rate/rate_prefectures/r08/index.html) / [2026年4月から始まる子ども・子育て支援金とは｜タヨロウ](https://www.tis.amano.co.jp/faq_column/4474/)（確認日2026-08-08）
- 💡 **記事ネタとして強い**: 「2026年から給与明細の健康保険料がちょっと増えているのは子ども・子育て支援金のせい」は、50代会社員が自分の明細を見て確かめられる話です

### まとめ表

| | 厚生年金保険料からの逆算 | 健康保険料からの逆算 |
|---|---|---|
| 料率 | 18.3%（全国一律・固定） | 都道府県別／健保組合別 |
| 労使負担割合 | 完全折半 | 協会けんぽは折半だが健保組合は独自 |
| 上乗せ | なし | 介護保険料・子ども・子育て支援金が混在 |
| 端数 | 出ない | 出る（50銭以下切捨て/50銭超切上げ） |
| **逆算のしやすさ** | **◎ 推奨** | △ 難しい |

## A-4. 逆算するときの落とし穴（読者が間違えやすい点）

記事の「注意書き」ボックスにそのまま使える形で並べます。

### ① 明細の金額は「本人負担分」＝すでに折半後
`÷ 0.183` ではなく **`÷ 0.0915`**。ここを間違えると標準報酬月額が半分になります。

### ② 賞与が出た月の明細で逆算してはいけない
賞与の保険料は**標準賞与額 × 保険料率**で別に計算されます（標準報酬月額とは別物）。賞与月の明細は保険料欄が膨らむため、逆算すると大きく狂います。
出典: [厚生年金保険の保険料｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)

### ③ 健康保険と厚生年金では「等級の番号」が別物
同じ標準報酬月額340,000円でも、**厚生年金では21等級／健康保険では24等級**です。

| | 等級数 | 下限 | 上限 |
|---|---|---|---|
| 厚生年金保険 | **32等級** | 88,000円 | 650,000円 |
| 健康保険（協会けんぽ） | **50等級** | 58,000円 | 1,390,000円 |

「私は◯等級です」という言い方は、どちらの制度の話かを言わないと通じません。
（協会けんぽの保険料額表では、厚生年金の等級が「24(21)」のようにカッコ書きで併記されています）
出典: 上記 令和8年度 保険料額表PDF（実データ確認済み）／[厚生年金保険の保険料｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)

### ④ 厚生年金には上限がある＝高収入だと逆算できない
厚生年金の標準報酬月額は**650,000円（32等級）で頭打ち**です。該当するのは**報酬月額635,000円以上**の人。

- 厚生年金保険料 全額: 650,000 × 18.3% = **118,950円**
- 本人負担（折半）: 650,000 × 9.15% = **59,475円**

つまり**明細の厚生年金保険料が59,475円の人は、「報酬月額が635,000円以上」ということしかわかりません**。実際の月給が70万円でも120万円でも同じ額になるため、逆算しても本当の給与額は出ません。
（一方、健康保険は50等級・上限1,390,000円まであるので、この層は健康保険料のほうが実態を反映します）
※数値は令和8年度 保険料額表（東京都）で確認済み

### ⑤ 介護保険料の有無で健康保険料欄が変わる
40歳〜64歳は介護保険第2号被保険者として**1.62%上乗せ**。
**65歳になると第1号被保険者に切り替わり、給与天引きが終わって年金からの特別徴収に移ります。** 50代読者にとって数年先の話なので、触れておくと親切です。
出典: [年齢に係る注意点｜木内社会保険労務士事務所](http://www.kiuchi-sr.com/article/13645104.html)（確認日2026-08-08）／⚠️一次情報での再確認を推奨

### ⑥ 70歳で厚生年金保険料は止まる（健康保険は続く）
70歳到達で厚生年金保険の被保険者資格を喪失し、**厚生年金保険料は引かれなくなります**（健康保険料は引かれ続ける）。70歳以降も働いている人の明細から逆算しようとすると「厚生年金の欄が無い」という事態になります。
出典: [厚生年金保険 被保険者資格喪失届／70歳以上被用者該当届｜日本年金機構](https://www.nenkin.go.jp/shinsei/kounen/tekiyo/hihokensha/20140218.files/70toutatushousaisetumei.pdf)（確認日2026-08-08）

### ⑦ 厚生年金基金の加入員は18.3%ではない
勤務先が厚生年金基金に加入している場合、**免除保険料率（2.4%〜5.0%の27段階）が控除**され、実際の料率は15.9%〜13.3%になります。この場合、18.3%での逆算は合いません。
（基金の多くは解散済みですが、残っている先もあります）
出典: [免除保険料率｜企業年金連合会](https://www.pfa.or.jp/yogoshu/me/me04.html)（確認日2026-08-08）

### ⑧ 公務員・私学教職員は別制度
共済組合の等級表は協会けんぽ・厚生年金の表と別建てです。読者対象を「会社員（厚生年金の被保険者）」に限定する一文を入れてください。

### ⑨ 端数処理は「健保・介護」で発生、「厚年」では発生しない
繰り返しですが、被保険者負担分の端数は**50銭以下切り捨て／50銭を超えたら切り上げ**。厚生年金では端数が出ないので、逆算がぴったり戻ります。

## A-5. 定時決定で決まった保険料は、いつの給与から反映されるか

### 制度の流れ

| ステップ | 時期 |
|---|---|
| 4月・5月・6月に支払われた報酬を集計 | 4〜6月 |
| 事業主が「算定基礎届」を提出（7月1日現在の全被保険者が対象） | 7月 |
| 決定された標準報酬月額の適用 | **その年の9月〜翌年8月** |
| 保険料としての発生 | **9月分から** |

- 出典: [定時決定（算定基礎届）｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20121017.html)（確認日2026-08-08）

### 給与天引きのタイミング（翌月控除／当月控除）

健康保険法・厚生年金保険法上、事業主は**「被保険者が負担すべき前月の標準報酬月額に係る保険料」を報酬から控除できる**とされており、**翌月控除が原則**です。ただし実務上は当月控除を採用している会社もあります。

| 勤務先の運用 | 新しい保険料（9月分）が反映される給与 |
|---|---|
| **翌月控除（原則・社長のお勤め先はこちら）** | **10月支給の給与から** |
| 当月控除 | 9月支給の給与から |

- 出典: [社会保険料の給与からの控除（徴収、天引き）｜解決社労士 柳田事務所](https://www.tama5cci.or.jp/hp/yanagida/?p=5510) ／ [第50号 定時決定した社会保険料は、いつの給与計算から控除？](https://www.firstitpro.com/section6/column50)（確認日2026-08-08）

### 💡 記事の締め切り／時期の観点（重要）

**この記事は「10月支給の給与明細を見る」直前に出すのが最も刺さります。**
9月中〜10月上旬公開なら、読者が実際に手元の明細で確認できるタイミングに重なります。逆に11月以降に出すと「もう見た」話になり価値が落ちます。編集長・社長に公開時期の判断をお願いします。

### 補足：定時決定以外で標準報酬月額が変わるケース
- **随時改定（月額変更届／月変）**: 昇給・降給で固定的賃金が変動し、報酬に著しい高低が生じた場合
- **育児休業等終了時改定・産前産後休業終了時改定**

理由：
1. 給付対象は**厚生労働大臣が指定した個別のコース**であり、指定には有効期間がある。年度ごとに指定が更新・入替えされる
2. **対象なのは「プレミアム本科生Plus」など一部の上位コースのみ**で、TACの行政書士講座すべてが対象ではない。社長がどのコースを受講したかが不明
3. 厚労省の[教育訓練講座検索システム](https://www.kyufu.mhlw.go.jp/kensaku/)は**現在指定されている講座を検索するもの**で、過去に指定されていたかを遡って調べる公開手段は見当たらなかった
4. 仮に対象コースでも、上記の**修了要件（正答率60%・出席率/提出率80%）を満たしていなければ支給されない**

→ 記事では「TACの行政書士講座には、現在も一般教育訓練給付の対象コースがある（2026年7月1日現在／2027年合格目標）」という**現在形の事実**に留め、「自分が受けたコースが対象だったかは、今となっては確かめようがない」と正直に書くのが安全です。

- 講座を受講して修了したのか
で扱いがまったく変わります。**前者なら修了証明書が出ないため、そもそも給付対象になりません。** ここは社長への確認が必要です。

## B-3. 市販の書籍で独学した場合は対象になるか

**対象になりません。** 理由は2つあります。

1. 教育訓練給付は「**厚生労働大臣が指定した教育訓練を受講し修了した場合**」に支給される制度であり、指定講座を受講していない独学は制度の枠外です
2. 支給対象となる「教育訓練経費」は、**教育訓練施設に支払った入学料・受講料**が基本。受講に必要な教材費は受講料に含まれる形で対象になり得ますが、**受講生が自分で買った市販の書籍・参考書は対象外**とされています
   - 具体的に対象外とされる例: 教育訓練施設が推奨する辞書・法令集などの補助教材、学校指定の制服・かばん、機器のレンタル料、修了後も価値が残る物品（PC・タブレット等）

- 出典: [教育訓練給付金の支給申請手続きについて｜厚生労働省](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000160564_00044.html) ／ [教育訓練経費の範囲と基準、「教育訓練経費」に含まれない費用の例](https://kyoikukunren.jp/a/3398)（確認日2026-08-08）
- ⚠️ 「書籍代は対象外」の明示は制度解説サイト由来です。記事に断定的に書く場合は、**「指定講座を受講していない独学は制度の対象外」という書き方**（こちらは制度の根幹なので確実）に寄せてください

- 一般教育訓練は**受講前の手続きが不要**なので、「知っていれば、申し込んで修了して、あとで申請するだけだった」——ここが後悔談として一番効きます
- 逆に言えば、**訓練前キャリアコンサルティングのような事前ハードルは無かった**のに逃した、という構図になります

## B-5. 申請期限を過ぎたら遡って申請できるか

### 公式の案内

**修了日の翌日から1か月以内**（一般・特定一般）。ユーキャンのFAQでも「修了日から1か月以内にハローワークで申請」と案内されています。

### ⚠️ 「2年以内なら申請できる」という説について

制度解説サイトが、**雇用保険法第74条第1項の消滅時効（2年）**を根拠に、期限超過でも時効成立までは申請可能と説明しています。

> 「失業等給付等の支給を受ける権利は、これらを行使することができる時から二年を経過したときは、時効によつて消滅する」（雇用保険法第74条第1項）

- 同サイトは、2015年4月1日の雇用保険法施行規則改正により「やむを得ない理由」がなくても申請が受理されるようになった、としています
- 出典: [【時効】教育訓練給付金の申請期限を過ぎたとしても2年以内であれば申請できます｜教育訓練給付金.JP](https://kyoikukunren.jp/a/668)（確認日2026-08-08）

### ⚠️⚠️ 記事に書く際の強い注意

1. **この「2年」説は民間の制度解説サイトの主張であり、厚生労働省・ハローワークの公式案内は一貫して「1か月以内」です。** 公式一次情報で裏が取れていません
2. 仮に2年ルールが正しいとしても、**社長が今から申請できる可能性は極めて低い**と考えられます。理由:
   - 学習時期が明らかに2年以上前とみられる（記録も残っていない）
   - 修了証明書がない（ユーキャンは修了日から1か月を過ぎると発行不可と明記）
   - 領収書がない
   - 受講したコースが指定講座だったか不明
3. **記事では「今から申請できます」と読者に期待させないでください。** 「制度上は時効2年という議論もあるが、実務上は修了証明書・領収書が揃わないと申請できないため、後から取り返すのは現実的に難しい」というトーンが正確です
4. 読者への実用的な結論は「**これから学ぶ人は、申し込む"前"に対象講座かどうかを厚労省の[教育訓練講座検索システム](https://www.kyufu.mhlw.go.jp/kensaku/)で調べること**」——これが記事の実用価値になります

> 社長ご本人がハローワークに電話で「◯年前に修了した講座について今から申請できるか」と1本確認していただければ、それ自体が**一次情報かつ社長の体験**になり、記事の独自性が一段上がります。

## C-5. 記事執筆時の注意点（リサーチ担当からの申し送り）

1. **キャンペーン価格が非常に多い**（スタディング・クレアール8/31まで、TAC早割7/1〜10/31、アガルート10%OFF等）。記事では**定価**を基準にし、「2026年8月時点」と明記してください
2. **LECの行政書士通学は同一商品ページ内でも価格に幅**があります（Web併用型/Web+DVD併用型で265,000円と298,000円）。「約25万〜30万円」とレンジで書くのが安全です
3. **資格の大原は社会人講座サイト（o-hara.jp）に価格掲載がなく**、校舎サイト（ohara.ac.jp）から取得しています。行政書士の教室通学は静岡校・名古屋校でのみ確認できました。開講校舎が限定的な可能性があります
4. **入会金**: TACは10,000円（簿記講座とFP3級は免除と公式明記）、大原は入学金6,000円。**LEC・大原の入会金の有無は完全には確認できませんでした**
5. **教育訓練給付（一般）対象講座が多数あります**（ユーキャン、フォーサイト、クレアール、スタディング、TAC等）。条件を満たせば受講料の20%が支給されるため、実質負担額は上表より下がります。**Bのセクションと直結する重要ポイント**です
6. **受験料は改定されます**。簿記は2024年4月に値上げ済み。FPは2026年度、行政書士は令和8年度の金額である旨を必ず記事に明記してください
7. **確認できなかった項目**: きんざい発行のFP問題集の現行年度版定価（公式サイトがドメイン移転中で404）
