## 3. 統合分析から見えた核心（3点）

### ① 直接アクセス75%は「質の低い流入」、本当の読者はSubstackにいる
- トップへの流入は多いが、平均滞在12秒・1PVで離脱（ちら見で終わる）
- 一方 Substack 経由は滞在18分・5.5PV。**熱心な読者が確実に存在する**
- 検索流入（月数セッション）を当てにするより、**Substock配信とトップページ内の回遊を先に固める**のが合理的

### ② 「更新ペースと流入の関係」は未検証のまま
- 週34（8/17〜8/23）は2本の記事を公開していたのに流入はわずか1セッション。翌週以降も6〜8セッションで推移
- **「公開が止まると流入も止まる」という当初の仮説は、この事実によって支持されない可能性が高い**
- 月55セッション規模のサイトでは、週単位の流入は1〜21の幅でランダムに変動しうる。統計的なノイズと区別するにはより長期のデータが必要
- 本来検討すべき仮説は「公開時にSNS・Substackへの発信が併走していたか」など、別の要因

### ③ トップページがランディングの82%なのに、そこから記事へ流れない
- 45セッションが `/` に着地し、ほとんどが1PVで去る（54PV/45セッション）
- 守りの改善（トップの導線強化）が最も費用対効果が高い

## 4. コード確認で見つかった実装上の問題（3点）

### 問題① PostCard が heroImage を表示していない（最大の機会損失）
- `src/components/PostCard.astro` は全記事が持つ `heroImage`（水彩画ヒーロー画像）を無視し、絵文字だけの色付きバナー（高さ80px）を表示している
- トップ・記事一覧・カテゴリタブのすべてでPostCardを使用 → **1ファイル修正で全ページに効く**
- 目を引く画像のない一覧はスクロールされない。離脱率と直結している可能性が高い

### 問題② ヒーローCTAが「記事を読む →」で /blog/ 行き
- 帰着先が記事リストの羅列。初見訪問者に「何から読むか」の答えを提示していない

### 問題③ 「初めての人の導線」が存在しない
- 実績のある記事（furusato-nozei-limit-guide、outdated-security-myths）への意図的な導線がゼロ
- 「このブログについて」セクションはあるが、読ませる導線ではない

## 5. 修正案（影響の小さい順・3ステップ）

### Step 1: PostCard にヒーロー画像を表示（最重要・効果大）

`src/components/PostCard.astro` を修正:

```astro
---
import type { CollectionEntry } from 'astro:content';

interface Props {
  post: CollectionEntry<'blog'>;
}

const { post } = Astro.props;
const { title, pubDate, category, description, emoji, heroImage } = post.data;
const hasHero = Boolean(heroImage); // heroImageが無い記事のフォールバック用

// （categoryStyles・formattedDate は既存のまま）
---

<a href={`/blog/${post.slug}/`} class="post-card">
  {hasHero ? (
    <div class="card-banner-img">
      <img src={heroImage} alt="" loading="lazy" class="card-hero" />
    </div>
  ) : (
    <div class="card-banner" style={`background: ${style.gradient}`}>
      <span class="card-emoji">{emoji}</span>
    </div>
  )}
  <!-- card-body 以下は既存のまま（category・title・description・date） -->
</a>

<style>
  .card-hero {
    width: 100%;
    height: 160px; /* 高さはカード幅に合わせて調整 */
    object-fit: cover;
    display: block;
  }
</style>
```

- `loading="lazy"` でページ速度を維持
- heroImageを持たない記事は絵文字バナーにフォールバック（既存表示を維持）
- 全24記事が対象。既存記事のfrontmatter修正は不要

### Step 2: ヒーローCTAを「目的別」に変える

`src/pages/index.astro` の `hero-cta` を単一リンクから2ボタンに:

```astro
<div class="hero-ctas">
  <a href="/blog/outdated-security-myths/" class="hero-cta">人気記事を読む →</a>
  <a href="/blog/" class="hero-cta-secondary">記事一覧 →</a>
</div>
```

- 一次選択の根拠: GSCで**平均7.9位・表示102回・クリック6回（サイト唯一の安定したクリック源）**
- 「何から読むか分からない」初見訪問者を実績記事へ直接導く

### Step 3: 「はじめての方へ」3本セクションを追加

`index.astro` の最新記事セクションの上（ファーストビュー直下）に新セクション:

```astro
<section class="start-here">
  <h2 class="section-title">はじめての方は、この3本から</h2>
  <div class="posts-grid">
    {/* PostCardを使い、3本のスラッグを固定指定 */}
    {/* ① seikatsu-bouei-shikin-guide（生活防衛資金） */}
    {/* ② outdated-security-myths（時代遅れのセキュリティ対策） */}
    {/* ③ life-money-plan-guide（人生のお金は3幕で考える） */}
  </div>
</section>
```

選定根拠:

| 記事 | 根拠 |
|---|---|
| seikatsu-bouei-shikin-guide | 内部被リンク16本（サイト最多）＝編集部が土台記事と認定。「保存版」ポジション |
| outdated-security-myths | GSC 7.9位・表示102・クリック6。検索実績No.1 |
| life-money-plan-guide | お金カテゴリの総覧。初心者の「何から読む？」に答える3幕構成 |

## 6. 併せて推奨する施策（コード以外）

1. **Substack配信の定期化**（滞在18分・5.5PVの熱心な読者が既にいる。新記事公開ごとに導入＋リンクを配信）
2. **公開ペース維持の効果は現時点で未検証**（週34に2本公開しても流入1セッションだった事実から、「公開すれば流入が増える」とは言えない。発信手段との併走や長期データでの検証が必要）
3. **「ハックロア」で1位を取りに行く**（リク提案どおり。outdated-security-mythsにH2見出しを追加する小修正）
4. **ふるさと納税・自動車保険・生命保険への追加投資は保留**（約200表示・クリック0の実績。3か月後に再測定）
5. **構造化データ（schema.org Article）追加**（ChatGPT流入が既に出始めている。生成AIエンジン対策）
