# §1 【最重要】逆算の具体的な手順

## 1-1. 結論の式

```
標準報酬月額 ＝ 給与明細の「厚生年金保険料」の額 ÷ 0.0915
```

この式が成り立つ根拠は3つあり、すべて一次情報で確認済みです。

| 根拠 | 内容 | 出典 |
|---|---|---|
| ① 保険料率は18.3%で固定 | 「平成29年9月を最後に引上げが終了し、厚生年金保険料率は18.3％で固定されています」 | [厚生年金保険の保険料｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)（確認日2026-08-13） |
| ② 労使折半 | 「事業主と被保険者とが半分ずつ負担します」→ 本人負担は 18.3% ÷ 2 = **9.15%** | 同上 |
| ③ 明細に載るのは本人負担分 | 「事業主は……被保険者の負担すべき前月の標準報酬月額に係る保険料を報酬から控除することができる」 | 厚生年金保険法 **第84条第1項**（e-Gov法令検索APIで条文取得、確認日2026-08-13） |

## 1-2. 電卓で追える手順（そのまま記事に使えます）

1. 給与明細の**「厚生年金」「厚生年金保険料」「厚年」**という欄の金額を見る（賞与が出ていない月の明細を選ぶ）
2. その金額を **0.0915 で割る**
3. 出た数字が**標準報酬月額**。1円単位の端数は出ないはず（後述1-4）
4. その金額を厚生年金の等級表に当てて**等級**を読む

## 1-4. なぜ端数で狂わないのか（記事の説得力になります）

厚生年金の標準報酬月額は**すべて2,000円の倍数**（88,000／98,000／104,000…340,000…650,000）です。
9.15% = 183/2000 なので、2,000の倍数に掛けると**必ず整数円**になります。

**実証**：日本年金機構の保険料額表PDFで、厚生年金の折半額は**全32行が「.00」**（8,052.00／9,516.00／31,110.00／59,475.00…）。1円未満の端数が1行も存在しません。

対して健康保険は端数が出ます。例：東京都・標準報酬月額1,390,000円の健康保険料 折半額は **68,457.5円**（→50銭以下切り捨てで68,457円）。ここが逆算の精度を落とします。

- 端数処理ルールの出典: 上記 日本年金機構 保険料額表PDFの注記「被保険者負担分の端数が５０銭以下の場合は切り捨て、５０銭を超える場合は切り上げて１円となります」／[保険料の計算方法について｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/nofu/20121026.html)

# §2 落とし穴（記事の信頼性を左右する部分）

## 2-1. ⚠️最大の罠：0.183で割ると「もっともらしい間違い」が出る

これは今回の調査で新しく見つけた、**記事の目玉になる指摘**です。

明細の額を誤って `÷ 0.183`（折半前の率）で割ると、答えは正しい標準報酬月額の**ちょうど半分**になります。問題は、**その半分の数字が等級表に実在してしまうことが多い**点です。

```
【正】31,110 ÷ 0.0915 = 340,000円 → 第21等級  ← 正解
【誤】31,110 ÷ 0.183  = 170,000円 → 第11等級  ← 表に実在するので間違いに気づけない
```

170,000円は第11等級として実在するため、**「表になくておかしい」と気づけません**。読者が静かに間違ったまま終わる危険があるので、記事では「割る数は0.0915（9.15%）です。18.3%ではありません」と、**赤字レベルで強調**してください。

- 実データ確認: 東京支部の令和8年度保険料額表PDFのヘッダーに、介護保険第2号被保険者に該当しない場合「9.85%」／該当する場合「**11.47%**」と表示（9.85 + 1.62 = 11.47）

**逆算への影響**：明細の「健康保険料」欄の金額が、40歳未満の同僚と40代の自分とで違う理由がこれです。健康保険料から逆算しようとすると、**自分が1.62%を負担しているかどうかを先に判定しないと式が立ちません**。厚生年金にはこの分岐がありません。

⚠️ **65歳到達時の扱い**：65歳で第1号被保険者に切り替わり、給与天引きが終わって市区町村が徴収する（原則、年金からの特別徴収）——という流れは複数の公的資料が示していますが、**協会けんぽの料率ページ本体には65歳到達時の徴収切替タイミングの明示的な記載がありませんでした**。記事で触れる場合は「64歳までが対象」という**協会けんぽが明記している範囲**に留め、65歳以降の詳細は断定しないでください。

### 組合健保：料率も負担割合も組合ごと

- 健康保険法第161条第1項（e-Gov法令検索APIで取得）: 「**被保険者及び被保険者を使用する事業主は、それぞれ保険料額の二分の一を負担する。**」——これが原則です
- ⚠️ ただし「健康保険組合は規約で事業主の負担割合を増やせる」（第162条とされる規定）は、**今回、条文本体を取得できませんでした**。記事では「健保組合では会社が半分以上を負担しているケースがある」という**実態の記述に留め、条文番号を挙げないでください**

## 2-6. 賞与（標準賞与額）は別扱い

# §3 なぜ厚生年金保険料から逆算するほうが確実なのか

社長・編集長の見立ては**正しいです**。理由を一次情報ベースで整理しました。

| 論点 | 厚生年金保険料からの逆算 | 健康保険料からの逆算 |
|---|---|---|
| **保険料率** | **18.3%（全国一律・2017年9月から固定）** | 協会けんぽは**都道府県支部ごと**（法律で規定）。健保組合は組合ごと |
| **労使負担割合** | **完全折半** | 協会けんぽは折半だが、健保組合は会社が多く負担することがある |
| **上乗せ要素** | **なし** | 介護保険料（40〜64歳のみ1.62%）＋子ども・子育て支援金（0.23%）が混ざる |
| **端数** | **出ない（全32行が.00）** | 出る（50銭以下切捨／50銭超切上）→逆算がズレる |
| **年度による変動** | **なし** | **毎年3月分から改定される** |
| **等級の上限** | 650,000円（32等級）で頭打ち | 1,390,000円（50等級）まである |
| **逆算のしやすさ** | **◎ 推奨** | △ 前提条件を4つ確定させないと式が立たない |

**記事での一言まとめ案（事実として正確です）**：
> 健康保険料から逆算するには「勤務先が協会けんぽか組合健保か」「どの都道府県か」「自分は40歳以上か」「端数はどちらに丸められたか」——この4つを全部確定させないと式が立ちません。厚生年金は、誰がどこで働いていても18.3%の折半、端数なし。だから逆算はこちらを使います。

⚠️ **健康保険側の唯一の優位点**：厚生年金の上限（650,000円）に張り付いている高所得者だけは、健康保険料（50等級・上限1,390,000円）のほうが実態を反映します。公平を期すなら一行入れてください。

# §4 定時決定そのものの基本（一次情報で確認済み）

## 4-1. 定時決定の流れ

出典: [定時決定（算定基礎届）｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20121017.html)（確認日2026-08-13）／[厚生年金保険の保険料｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html)

| ステップ | 内容（原文の表現） |
|---|---|
| 対象月 | 「7月1日現在で使用される全被保険者について、同日前3カ月間（**4月、5月、6月**）」に受けた報酬 |
| 届出 | **算定基礎届**（正式には「健康保険・厚生年金保険 被保険者報酬月額算定基礎届」） |
| 提出期限 | 「毎年**7月10日**まで」（10日が土日の場合は翌営業日） |
| 適用期間 | 「決定し直された標準報酬月額は、**9月から翌年8月まで**の各月に適用」 |
| 制度の位置づけ | 「毎年9月に、4月から6月の報酬月額を基に、標準報酬月額の改定が行われます（定時決定）」 |

**対象外となる人（原文の4類型）**: 「6月1日以降に資格取得した方」「6月30日以前に退職した方」「7月改定の月額変更届を提出する方」「8月または9月に随時改定が予定されている旨の申し出を行った方」

## 4-2. 【裏取り完了】9月分の保険料はいつの給与から引かれるか

前回メモではここが民間サイト由来でしたが、**今回、法律の条文そのもので裏を取りました。**

**厚生年金保険法 第84条第1項**（e-Gov法令検索APIで条文取得、確認日2026-08-13）:

> 「事業主は、被保険者に対して通貨をもつて報酬を支払う場合においては、被保険者の負担すべき**前月の標準報酬月額に係る保険料**（被保険者がその事業所又は船舶に使用されなくなつた場合においては、前月及びその月の標準報酬月額に係る保険料）を報酬から控除することができる。」

**「前月の」と明記されています。つまり法律上の原則は翌月控除です。**

| 勤務先の運用 | 9月分の新しい保険料が反映される給与 |
|---|---|
| **翌月控除（法律上の原則。厚生年金保険法第84条第1項）** | **10月支給の給与から** |
| 当月控除（実務上、採用している会社もある） | 9月支給の給与から |

⚠️ **書き方の注意**：第84条は「控除することができる」という**任意規定**です。「当月控除は違法」とは書かないでください。実務上、当月控除を採用している会社は存在します。記事では「法律の原則は翌月控除（＝10月の給与）。ただし会社によっては9月の給与から変わるので、両方の月の明細を見比べるのが確実」という書き方が正確かつ実用的です。

💡 **同条第2項に賞与の規定もあります**：「被保険者の負担すべき標準賞与額に係る保険料に相当する額を当該賞与から控除することができる」——賞与の保険料が賞与そのものから引かれる根拠です（§2-6と接続）。

💡 **同条第3項**：「事業主は、前二項の規定によつて保険料を控除したときは、**保険料の控除に関する計算書を作成し、その控除額を被保険者に通知しなければならない**」——これが給与明細の法的根拠のひとつです。「明細に厚生年金保険料の額が書いてあるのは法律で決まっているから」という一文は、記事の冒頭で効きます。

## 4-3. 随時改定（月額変更届）との違い

出典: [随時改定（月額変更届）｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-02.html)（確認日2026-08-13）

**該当する3つの要件（原文）**:
1. 「昇給または降給等により**固定的賃金に変動**があった」
2. 「変動月以後引き続く**3カ月の報酬の平均額**により算出した標準報酬月額と従前の標準報酬月額との間に**2等級以上の差**が生じた」
3. 「変動月以後引き続く3カ月の報酬の**支払基礎日数が17日**（特定適用事業所に勤務する短時間労働者は11日）**以上**である」

**適用時期**: 「変更後の報酬を初めて受けた月から起算して**4カ月目**（例：4月に支払われる給与に変動があった場合、**7月**）の標準報酬月額から改定されます」

**例外**: 「標準報酬月額の**上限または下限にわたる等級変更の場合は、1等級差でも**随時改定の対象となります」

**固定的賃金とは**: 「支給額や支給率が決まっているものをいいます」（例：昇給・降給、給与体系の変更）

### 定時決定と随時改定の比較表（記事にそのまま使えます）

| | 定時決定 | 随時改定 |
|---|---|---|
| きっかけ | 毎年自動的に | 固定的賃金の変動 |
| 見る月 | **4月・5月・6月** | 変動月からの**3カ月** |
| 適用開始 | **その年の9月から** | 変動月から**4カ月目**から |
| 適用期間 | 9月〜翌年8月 | 次の定時決定または次の随時改定まで |
| 届出 | 算定基礎届（7月10日まで） | 月額変更届（速やかに） |

**記事に入れると親切な一文**: 残業代が増えても、それだけでは随時改定になりません（残業代は固定的賃金ではないため）。ただし**定時決定では4〜6月の残業代も報酬に含まれる**ので、「4〜6月に残業すると1年間保険料が高くなる」という話につながります。

# §6 【納品物】読者向け「逆算の手順」

そのまま記事に使える形で書きます。数値例は**日本年金機構の公式保険料額表の実データに当てて検算済み**です。

---

## 給与明細から標準報酬月額を逆算する4ステップ

**1. 賞与が出ていない月の給与明細を用意する**
　賞与が支給された月の明細は、厚生年金保険料の欄に賞与分（標準賞与額に対する保険料）が上乗せされていて、逆算が狂います。ふつうの月の明細を選んでください。

**2. 「厚生年金」「厚生年金保険料」「厚年」と書かれた欄の金額をメモする**
　健康保険料の欄ではありません。**厚生年金の欄**です。ここに書かれているのは、会社と折半したあとの**あなたの負担分**です（厚生年金保険法第84条第1項）。

**3. その金額を 0.0915 で割る**
　厚生年金の保険料率は**全国一律18.3%**、これを会社と**半分ずつ**負担するので、あなたの負担率は**9.15%（＝0.0915）**です。
　⚠️ **0.183で割らないでください。** 答えがちょうど半分になり、しかもその数字も等級表に実在してしまうため、間違いに気づけません。

**4. 出た数字を厚生年金の等級表に当てて、等級を読む**
　厚生年金は**第1等級（88,000円）から第32等級（650,000円）までの32等級**です。
　等級表 → [保険料額表（令和2年9月分〜）｜日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/ryogaku/ryogakuhyo/20200825.html)

---

### 数値例：明細の厚生年金保険料が「31,110円」だったら

```
ステップ3： 31,110 ÷ 0.0915 ＝ 340,000

→ あなたの標準報酬月額は 340,000円
→ 厚生年金の 第21等級（全32等級中）
→ 4月〜6月の平均報酬月額が、330,000円以上350,000円未満の範囲にあった
```

公式の保険料額表（令和8年度）で答え合わせをすると、第21等級・標準報酬月額340,000円の行には、
**全額 62,220円 / 折半額 31,110円**
と書かれています。明細の金額とぴったり一致します。

**もうひとつ：明細が「20,130円」だったら**
```
20,130 ÷ 0.0915 ＝ 220,000
→ 標準報酬月額 220,000円 → 第15等級（報酬月額 210,000円以上230,000円未満）
```
（公式表の第15等級：全額 40,260円 / 折半額 20,130円。一致）

---
