## 収集方法（再現できるように）

- X検索の演算子 `min_faves:数字 lang:ja -filter:replies since:日付` を使用
- 検索語：`AI 使い方` / `ChatGPT 使い方` / `生成AI 仕事` / `Claude Code` / `ChatGPT OR 生成AI` など
- 各投稿のいいね・ブックマーク数はDOMの `aria-label` から取得、投稿者のフォロワー数は各プロフィールページで実測
- **「いいね ÷ フォロワー」が高い順**に10本を選定（＝フォロワー数に対して不自然に伸びた投稿）

## 伸びている理由（抽出した8パターン）

### 1. 冒頭2行で「あなたは今、損か危険な状態だ」と名指しする
一般論ではなく**読者本人を当事者にする**書き出し。

- 「今すぐやめてーー！！！ ChatGPTに人生相談してる人 危ないってーー！！！」
- 「炎上覚悟で言うけど、ChatGPTに『〜して』って言ってる人、AI弱者認定されてますwww」
- 「もうええでしょう。ChatGPTの使い方は、十分わかったでしょう」
- 「なぜ時間のない会社員ほど、アフィやSNSみたいな激ムズな副業を選ぶんだろう？」

### 2. 解決策を必ず固有名詞で出す
「便利なAIがあります」では伸びない。**明日そのまま試せる名前**が入っている。
Claude / Codex / Napkin AI / Gamma / NotebookLM / GPT-Image2 / Kling3.0 Pro / Suno / grill-me / Seedance 2.5 / Skill Recorder / Mercor

### 3. 「用途 → ツール」の一行マッピング形式
1位の@taiga_aiiは、この形だけで6,294いいね。

```
文章作成なら → Claude
サイト,LP作成なら → Codex
図解にするなら → Napkin AI
スライド作るなら → Gamma
```
縦にスキャンできて、読むのに努力がいらない。

### 4. ブックマークがいいねを上回る（＝解説系の勝ちパターン）
10本中5本で **ブクマ > いいね**。pekotyan_12は いいね10,782 < ブクマ13,865。
**共感されるより「あとで使うから保存」される投稿が伸びている。**

### 5. 権威を借りる／一次情報を貼る
- 「**Anthropic公式**が『うちの社員がClaude Codeをどう使ってるか』のPDFを出してた」
- 「**Microsoft**のSkill Recorderは発想が面白い」
- 公式プロンプトガイドのURLをそのまま貼る（@tanabe_fragm）

小さいアカウントでも、**公式が言っていることを持ってくれば信用が乗る**。

### 6. 価値を必ず金額に換算する
「スクールに3万払う前に」「時給50ドル（約7,700円）」「含み益率+45%超え」「月10万以上の案件」。
"便利"ではなく**いくら得するか・いくら損するか**で書かれている。

### 7. 1投稿で完結させず、続きを読ませる
「中身をざっくりシェアします」「理由説明するからーー！！！」でスレッドへ送る。
@taiga_aiiは**大量の空白改行を入れて強制的に「続きを読む」を発生させる**手法を使っている。

### 8. 自分で試した結果を数字付きで出す
@t2aman1e（+45%）、@tanabe_fragm（実際の作成手順）。**他人がコピーできない一次体験**が効いている。

## 共通して「書かれている」もの

1. **ツール名・機能名の固有名詞**（10本すべて）
2. **手順そのもの**（コピペできる／すぐ試せる形）
3. **読者の現状否定**（〜してる人、損してます／危ないです）
4. **金額換算**（7本）
5. **公式・一次情報へのリンク**（5本）

## 共通して「書かれていない」もの

- 丁寧な前置き・自己紹介（全員いきなり本題）
- 「〜だと思います」の曖昧表現
- ハッシュタグの乱用（0〜1個。多くはゼロ）
- **画像**（10本中9本がテキストのみ。動画1本。画像がなくても伸びている）

## ⚠️ この分析の限界（誇張しないための注記）

- サンプルは**10件・1日分のスナップショット**。相関であって因果ではない
- 選定したアカウントは**AI×副業・マネタイズ系に偏っている**（プロフィールに「月◯万円達成」と書く層）。naoki-blogの読者（50代・家計/制度）とは**客層が違う**
- とくに「1. 読者の現状否定」「6. 金額換算」を強く出すと、YMYL分野では煽りと受け取られるリスクがある。**そのまま真似すべきではない**
