# 2.【本題】表示回数はあるのか、ゼロなのか

## 2-1. 結論：**表示回数はゼロではありません。しかし「壊滅的に少なく、しかも減り続けて」います。**

これは依頼にあった二択のどちらでもない、**第三の状態**です。正確に言うと：

> **表示回数はある（＝インデックスされ、検索結果のどこかには出ている）。**
> **しかしCTRの問題ではない（＝クリック率は正常値）。**
> **表示回数の「絶対量」そのものが、事業として成立しない水準にある。**

## 2-2. 実測値（Coverageエクスポート sheet1 の生データ）

| 期間 | 表示回数 合計 | 日数 | 1日平均 |
|---|---|---|---|
| 全期間 2026-05-30〜08-05 | **455** | 68 | 6.69 |
| 6月 | 304 | 30 | **10.13** |
| 7月 | 124 | 31 | **4.00** |
| 8/1〜8/5 | 23 | 5 | 4.60 |
| **直近30日（07-07〜08-05）** | **111** | 30 | **3.70** |

表示回数が完全に0だった日は68日中2日のみ。**つまり「圏外でまったく表示されていない」わけではありません。**

## 2-3. この数字が意味すること（厳しめに）

**サイト全体で1日3.7回しか表示されていません。** 月換算で約110回です。これを20本の記事で割ると、**1記事あたり月5.5回**。

比較の目安として、**月間検索1,000回のキーワードで10位に入っているページ1枚だけで、月1,000回前後の表示回数**が発生します。サイト全体でその1/10しかないということは、

> **どの記事も、意味のある検索ボリュームを持つキーワードで「人の目に触れる順位帯」に入っていない。**

と読むのが妥当です。順位データが無いので断定はできませんが、**表示回数の絶対量そのものが、順位が相当低いことの間接証拠**になっています。

## 2-4. 【最重要】記事を増やしたのに表示回数は減っています

これが今回いちばん重い発見です。

| 時点 | 公開記事数 | 表示回数/日 |
|---|---|---|
| 6月 | 約7〜10本 | **10.13** |
| 7月 | 約19本 | **4.00** |
| 直近30日 | 20本 | **3.70** |

**記事数が約2倍になった一方で、表示回数は約63%減りました。**

「記事を増やせば流入が増える」という前提が、**このサイトの実測データでは成立していません。** ここを直視せずに24本目・25本目を書いても、同じ結果になる可能性が高いと考えます。

⚠️ 減少の原因は、このデータだけでは特定できません。考えられる要因（断定不可）:
- 6月の記事統廃合でURLが10本消えた時期と重なる
- Googleが新規サイトを一時的に高く出す「ハネムーン期間」の終了
- Googleのアルゴリズム変動・季節要因

**原因を1つに決めつけないことをおすすめします。**

## 2-5. CTR（タイトル・descriptionの問題）は**シロ**です

依頼の分岐「表示回数はあるがクリックされない → タイトル・descriptionの問題」を検証しました。**該当しません。**

**根拠1: 概算CTRは正常値**

GA4のorganicセッション23件（google 14 / yahoo 6 / bing 3）に対し、GSC表示回数455。
→ 概算CTR **約3〜5%**。これは異常に低い数値ではありません。

⚠️ 厳密な比較ではありません（GSCはGoogleのみ／GA4セッション≠GSCクリック／期間も完全一致しない）。あくまで桁の確認です。

**根拠2: title/descriptionの字数は全23本が基準内**

全記事を実測しました。

| 項目 | 基準 | 結果 |
|---|---|---|
| title | 25〜37字 | **23本すべて基準内**（最短25字 / 最長35字） |
| description | 80〜120字 | **23本すべて基準内**（最短80字 / 最長115字） |

**→ タイトルとdescriptionを書き直しても、この問題は解決しません。** 分母（表示回数）が110/月しかないので、CTRを仮に2倍にしても月の流入は数十件増えるだけです。**打ち手として費用対効果が合いません。**

## 2-6. 切り分けの結論

| 仮説 | 判定 |
|---|---|
| インデックスされていないから読者が来ない | **✗ 否定**（19/20本は登録済み） |
| 表示回数はあるがクリックされない（タイトル・desc問題） | **✗ 否定**（CTRは正常・字数も全数基準内） |
| **表示回数の絶対量が足りない（＝順位が低い／狙うKWで勝負になっていない）** | **◎ これが本体** |

構造的な理由を3つ挙げます。

1. **YMYL（お金）× 金融ジャンルはGoogleが最も厳しくE-E-A-T（経験・専門性・権威性・信頼性）を要求する領域**です。ドメイン開設3ヶ月・運営者の公的な権威付けが薄い個人サイトが、金融庁・証券会社・大手比較メディアと同じ土俵で競うのは、**時間の問題ではなく構造の問題**です。5年待っても順位が入れ替わる保証はありません。

2. **アフィリエイト単価が高いキーワードほど、競合が広告費と人員を投下しています。** クレジットカード・自動車保険・証券口座は、企業が年間数千万円規模を投じる市場です。ここに個人が正面から入るのは、資本の非対称性の面で不利です。

3. **外部からの被リンクがほぼ無い状態です。** GA4の参照元にも、実サイトからの自然な流入は見当たりません（substack/a8/githubは自社・身内）。YMYLでは特に、外部からの引用・言及が順位の土台になります。

# 4. 勝てる可能性のあるキーワードはどこか

## 4-1. 選定の考え方

3章の結論は「大手と同じ土俵に立たない」です。**大手が書けない＝書く動機が無いか、利益相反で書けない領域**を狙います。

判定軸を2つ置きました。

- **一次情報の希少性**: 社長本人でなければ書けないか
- **収益性**: AdSense/アフィリエイトにつながるか

⚠️ **以下の提案に検索ボリュームの裏付けはありません**（Ahrefs不通のため）。ボリューム確認前の仮説です。

## 4-2. 提案（優先度順）

### 【最優先】A. 終身保険を解約した実体験

| 項目 | 内容 |
|---|---|
| 想定KW | 終身保険 解約 返戻金 いくら / 終身保険 解約 後悔 / 50代 終身保険 やめた |
| **なぜ勝てるか** | **保険会社・保険代理店・保険相談サイトは、この記事を絶対に書けません（利益相反）。** 検索結果に「実際に解約した人の記録」がほぼ存在しない構造的な空白地帯です |
| 一次情報 | ◎ 社長が実際に解約済み |
| 収益性 | ○ 保険見直し系アフィリは単価が高い |
| 注意 | 具体的な返戻金額を出せるほど強くなります。出せる範囲は社長のご判断で |

### 【最優先】B. 潰瘍性大腸炎（難病）× お金・仕事

| 項目 | 内容 |
|---|---|
| 想定KW | 潰瘍性大腸炎 医療費 実際 いくら / 難病 医療費助成 申請 やってみた / 潰瘍性大腸炎 働きながら 仕事 / 持病 生命保険 入れない どうした |

| 一次情報 | ◎ 最強クラス。難病指定を抱えながら製造業で継続就労している50代という組み合わせは希少 |
| 収益性 | △〜○ 保険・医療費関連。ただし「持病があると入れる保険が限られる」ため商材は限定的 |

# 5. 総括：なぜ読者が来ないのか（構造の切り分け）

```
23本書いた
  ↓
インデックスはされている（19/20本）        ← ここは問題なし ✓
  ↓
検索結果に表示される回数が月110回しかない   ← ★ここがボトルネック
  ↓
CTRは正常（3〜5%）                        ← ここも問題なし ✓
  ↓
organic流入 90日で23セッション
```

**ボトルネックは1箇所です。「表示回数の絶対量」。**
そしてその原因は、**技術的な不備ではなく（8/8の点検で不備ゼロを確認済み）、記事の6割が構造的に勝てないキーワードに投下されていること**にあると考えます。

**したがって、いま効果が見込めない打ち手:**

| 打ち手 | なぜ効かないか |
|---|---|
| タイトル・descriptionの改善 | CTRは正常。分母が110では改善幅が誤差 |
| 内部リンクの追加 | すでに十分。新記事2本への追加は軽微な改善のみ |
| サイトの技術改修 | 不備はゼロ。直す対象が無い |
| **同じ路線で24本目を書く** | **記事数2倍で表示回数63%減という実測がある** |

# 6. 次回までに社長にお願いしたいこと

## 【最優先】検索パフォーマンスのエクスポート（5分）

**これが今回いちばんのお願いです。**

`編集部/データ/` にある12個のGSCエクスポートは、**すべて「インデックス作成（Coverage）」レポートです。「検索パフォーマンス」レポートは1件もエクスポートされていません。**

そのため、**このサイトが「どんなキーワードで」「何位に」表示されているかを、私は一度も見たことがありません。** 3章の競合度評価が構造的な判断にとどまっているのも、4章の提案にボリューム裏付けが無いのも、根はここにあります。

**手順:**
1. Search Console を開く
2. 左メニューの **「検索結果」**（「インデックス作成」ではありません）をクリック
3. 期間を **「過去3か月」** に設定
4. 「クエリ」「ページ」「国」「デバイス」のタブが並んだ表の**右上の「エクスポート」→「Excel/CSV」**
5. `編集部/データ/` に保存

**これが手に入ると、いま推測でしか言えない以下が確定します:**

| 今わからないこと | エクスポートで判明すること |
|---|---|
| どのキーワードで表示されているか | クエリ一覧（実際に検索された言葉） |
| 平均掲載順位 | 圏外（50位以下）なのか、あと一歩（11〜20位）なのかが分かる |
| **あと一歩の記事はどれか** | **11〜20位の記事があれば、そこを補強するのが最短の打ち手になります** |
| 記事ごとの実クリック数 | どの記事が唯一機能しているか |

**特に重要なのは「11〜20位（2ページ目）の記事の有無」です。** もし2ページ目にいる記事があれば、**新記事を書くより、その記事を強化するほうが圧倒的に投資効率が高い**です。逆に全記事が50位以下なら、3章の厳しい評価が裏づけられ、**路線変更を決断する材料**になります。
