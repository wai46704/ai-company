### 実害はどの程度か（平たく言うと）

**「記事の一番上の絵が、割れた画像アイコンになっている」だけ。ページそのものは正常です。**

- 記事の文章・タイトル・見出し・内部リンクはすべて正常に配信されており、**検索順位やインデックス登録への直接の悪影響はほぼありません**。Googleは画像1枚の欠けでページを低評価しません。
- **SNSシェアへの影響はゼロです。** 検証の結果、このサイトは全ページで OGP（SNSに貼ったときのプレビュー画像・タイトルを指定するタグ）を**元々1つも出力していません**。つまり今回の画像欠落でシェア表示が悪化したわけではなく、最初からプレビュー画像は出ていません。
- 実際に効くのは**見た目の印象**です。①最新記事＝トップページから最初に読まれる記事で画像が割れている、②AdSense審査でも人が実際にページを見るため「作りかけのサイト」という印象を与えうる。この2点が実質的なリスクです。
- 緩和材料: `alt` にタイトル文字列が入っているため、画像が読めない環境ではタイトル文が表示され、真っ白にはなりません。

**総括: SEO上の緊急事態ではないが、見た目の欠陥として即日直す価値がある。作業は数十秒。**

## 2. OGP タグが全ページで未実装（新規発見・優先度 高）

`src/layouts/BaseLayout.astro` が出力する meta タグは以下の3つのみ:

```
<meta charset="UTF-8">
<meta name="viewport" content="...">
<meta name="description" content="...">
```

`og:title` / `og:description` / `og:image` / `og:type` / `og:url` / `twitter:card` が**1つもありません**。

影響: X（Twitter）やメルマガに記事URLを貼っても、画像付きのカードにならず「ただのリンク文字列」で表示されます。ツムギがX告知を運用している以上、クリック率に直結する取りこぼしです。せっかく21記事すべてにアイキャッチ画像を用意しているのに、SNS上では一度も使われていません。

対応案: `BaseLayout.astro` に OGP タグを追加し、`BlogLayout` から `heroImage` を絶対URL（`https://naoki-blog.com` + パス）で渡す。1ファイルの改修で全21記事に一括で効きます。実装は編集長にお任せします。
