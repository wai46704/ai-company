## 0. この文書の目的

社長の目標は2つあります。

1. **70歳まで働ける収入源をつくる**
2. **収益が安定したら、定年（60歳）前でも退職する**

今、この2つに対して「いくら必要で、いつまでに、どうやって」という設計がありません。
手段（AdSense・アフィリエイト・メルマガ）の話はあるのに、目標金額がない状態です。

この文書は、**先に必要額を確定させ、そこから手段を選ぶ**ための土台です。

## 3. 逆算の起点 ―― 本当に必要なのは「月いくら」ではない

ここが今回いちばん重要な指摘です。

### 60歳で退職すると、10年間の完全な空白ができる

社長が既に決めていることを並べると、こうなります。

- 継続雇用は **65歳まで**
- 公的年金は **70歳まで繰下げ**
- 新NISAの取り崩しも **70歳から**

つまり **60歳で退職した場合、60歳〜70歳の10年間は、公的年金もNISAも入ってきません。**
（以前の朝会で「65〜70歳の5年の空白」を指摘しましたが、60歳退職を前提にすると空白は**10年**に伸びます。）

### 必要額の式

```
必要額 ＝ （退職後の月の生活費 × 12 × 10年）
        －（60歳時点の金融資産 ＋ 退職金）
```

この「必要額」を、ブログ等の収入で埋めることになります。

**参考：生活費別の10年分**

| 月の生活費 | 10年分 |
|---|---|
| 20万円 | 2,400万円 |
| 25万円 | 3,000万円 |
| 30万円 | 3,600万円 |

もし右辺（資産＋退職金）が左辺を上回るなら、**そもそもブログ収益は退職の条件になりません。**
足りない場合に初めて、「毎月いくら稼げば埋まるか」が決まります。

**→ この3つの数字が分からないと、月5万円が目標なのか月30万円が目標なのか決まりません。第6章で確認します。**

## 4. 手段ごとの「必要な読者数」―― AdSenseは主軸にならない

仮に **月10万円** と **月30万円** を目標にした場合、手段ごとに必要な規模を試算します。
（単価・成約率は一般的な相場を控えめに置いた概算です。実測ではありません）

### AdSense

- 前提：金融系のRPM（1,000PVあたり収益）を400円と仮定
- 月10万円 → **25万PV/月**
- 月30万円 → **75万PV/月**

現状の外部流入は月あたり約30セッション。25万PVは **約8,000倍**。

### アフィリエイト（証券口座・カードなど）

- 前提：1件5,000円、成約率0.5%
- 月10万円 → 20件 → **4,000セッション/月**
- 月30万円 → 60件 → **12,000セッション/月**

現状の約30セッションから見て **約130倍**。

### 有料コンテンツ（有料メルマガ・note・講座）

- 前提：月額500円
- 月10万円 → **有料購読者200人**
- 月30万円 → **有料購読者600人**

ただし有料200人を得るには、無料読者がその数十倍必要です。今は無料購読者1人なので、見た目の数字ほど近くはありません。

### この試算からの結論

**必要な読者数の少ない順に：有料コンテンツ ＜ アフィリエイト ＜＜ AdSense**

既存の戦略メモは「PVを量産してAdSense」という発想でしたが、**AdSenseを主軸に置くと、必要PVが桁違いに現実離れします。**
AdSenseは「読者が増えれば自動的に少し入る」おまけとして扱い、設計の主軸は単価の高い方に置くべきです。

（※AdSense審査そのものは、サイトの信頼性の証明として意味があります。申請はこのまま進めて問題ありません。）

## 5. 今の本当のボトルネックは、収益ではなく「読者がいないこと」

第4章のどの手段も、必要なのは読者です。
**23本書いて、外部の検索読者が90日で23セッション。** ここが解決しない限り、どの収益手段を選んでも結果は同じです。

リクの調査（`編集部/データ/検索流入ボトルネック分析_2026-08-11.md`）で、原因の切り分けが進みました。

### 分かったこと

**① 「表示はあるがクリックされない」でも「インデックスされていない」でもなかった**

第三の状態でした。**表示回数はゼロではないが、絶対量が壊滅的**です。

| 期間 | 1日あたりの表示回数 |
|---|---|
| 6月 | 10.13回 |
| 7月 | 4.00回 |
| 直近30日 | **3.70回** |

月換算で約110回。**1記事あたり月5.5回**です。

**② タイトル・descriptionの改善は効かない**

CTRは概算3〜5%で正常。23本すべてtitle 25〜35字・description 80〜115字の基準内。
**分母が月110では、改善しても誤差にしかなりません。** ここに工数を割くのは無駄です。

**③ GA4と数字が一致している**

月110表示 × CTR 4% ＝ 月4.4クリック。
GA4の organic 23セッション/90日（月あたり約8）とほぼ整合します。**別々のデータが同じ結論を指しています。**

### 表示回数の減少については、原因の断定を保留します

リクは「記事数が2倍になったのに表示63%減 ＝ 書いても増えない」と結論づけましたが、**編集長として、この因果は早いと判断します。**

理由：**2026-07-20に旧記事10本を統廃合し、URLをリダイレクトしています**（コミット `00cd4b3`）。

- 統廃合前は実質33本相当。「記事数が2倍」という前提が成立していません
- Googleがリダイレクトを処理して評価を移すには、通常1〜3か月かかります
- 直近30日（7/12〜8/11）は、まさに統廃合をまたいだ期間です

つまり、**今の落ち込みは統廃合による一時的なものである可能性が残っています。**
ただし統廃合前の6月でも月300表示程度であり、**絶対量が壊滅的であるという事実は変わりません。**

**→ 路線変更の判断は、統廃合から2か月経つ9月下旬の再測定まで保留します。**

### まだ分かっていない、いちばん重要なこと

**「どのキーワードで何位なのか」を、一度も見ていません。**

`編集部/データ/` にあるGSCエクスポート12個は、すべて「インデックス作成」レポートでした。「検索パフォーマンス」レポートが1件もありません。

これが分かると、決定的な分岐が判明します。

- **11〜20位（検索結果2ページ目）の記事がある** → 新記事を書くより、**そこを補強する方が圧倒的に効率が良い**
- **全部50位以下** → 路線変更を決断する材料になる

**費用ゼロで、Ahrefs契約より情報量が上です。第6章【D】として社長にお願いします。**

**収益手段の議論より、この切り分けの方が先です。**

## 6. 社長に決めていただきたいこと

### 【A】必要額を確定するための3つの数字

逆算の式に入れる数字です。**概算・ざっくりで構いません。** ここが決まらないと目標金額が決まりません。

1. 退職後に必要な**月の生活費**はいくらか
2. **60歳時点で見込める金融資産**はいくらか（NISA含む）
3. **退職金**はいくら見込めるか
   - ※在職老齢年金の記事で「報酬比例部分の見込み額はまだ見ていない」と書かれていました。退職金も同じ状態であれば、「未確認」で構いません。その場合は**確認すること自体を次のタスクにします。**

（この3つは会社の制度や個人の資産に関わるため、**記事には一切書きません。** 逆算の内部資料としてのみ使います。）

### 【B】収益の主軸をどこに置くか

現在のブログの軸は「お金・年金・保険」（YMYL領域）です。この領域は大手金融メディアが圧倒的に強く、個人ブログが検索で上位を取るのは年単位の戦いになります。

一方で、社長には**もう1つの軸**があります。連載「AI編集部の成長記録」です。

| | お金・年金・保険（現在の軸） | AI編集部の運営記録（もう1つの軸） |
|---|---|---|
| 競合 | 大手金融メディアが圧倒的に強い | 非エンジニアの実運用記録は稀 |
| 社長にしか書けないか | 体験談は書ける（持病・保険解約・繰下げの判断） | **ほぼ社長にしか書けない** |
| YMYLの壁 | 高い（信頼性の審査が厳しい） | 低い |
| 高単価商材にできるか | アフィリエイト中心 | 有料note・講座など単価の高い形にしやすい |
| 70歳まで続けられるか | 続けられる | 続けられる |

**選択肢：**
- ア）お金の軸を主軸のまま続け、AI編集部は連載として補助的に置く（現状維持）
- イ）**収益の主軸をAI編集部側に移し**、お金の記事は信頼性の土台として続ける
- ウ）両方を並行し、半年後に流入の実績が出た方に寄せる

**編集長としての意見：** イかウを推します。理由は第4章の通り、単価の高い商材ほど必要読者数が少なくて済み、AI編集部の軸の方が「社長にしか書けない＝競合が弱い」からです。ただし**これは事業の方向を変える判断なので、社長が決めることです。**

**なお、リクとは見立てが分かれています。** リクはAI編集部の軸を「競合の弱さは唯一の◎だが、収益性は低い。サイトを強くする投資と割り切るべき」と評価しました。これはアフィリエイト案件の単価を基準にした判断で、その前提では正しいです。私が「単価が高い」と言っているのは有料note・講座を想定した話なので、**前提が違うだけで矛盾はしていません。** どちらの収益手段を想定するかで結論が変わる、ということです。

### 【D】Search Consoleの「検索パフォーマンス」をエクスポートしてください（5分・費用ゼロ）

第5章の通り、**どのキーワードで何位なのかを、編集部はまだ一度も見ていません。**

手順：Search Console 左メニュー →「検索結果」→ 期間を過去3か月 → 右上の「エクスポート」

これが無いと、「2ページ目の記事を補強する」のか「路線を変える」のかを決められません。

### 【E】キーワードの方向性（リクの提案）

リクが挙げた「企業が利益相反で書けない／当事者でないと書けない」領域です。参考として記載します。

| | 領域 | 補足 |
|---|---|---|
| ① | 終身保険を解約した実体験 | 保険会社が絶対に書けない領域。単価も高い |
| ② | 潰瘍性大腸炎 × お金と就労 | 当事者性が必須。**ただし健康YMYLのため医学的な断定は禁止**。費用・手続き・両立の話に限定 |
| ③ | 年金70歳繰下げの「決断」の記録 | 大手はシミュレーションしか書けない |
| ④ | 車両保険を外した判断 | 同上 |
| ⑤ | Claude Code / AI編集部 | 競合の弱さは唯一の◎ |

**※②については、社長が非公開と決めた事項（5年ほど受診していないこと／会社の一部の人だけが病名を知っていること）には一切触れません。**

### 【C】退職を判断する条件

「収益が安定したら退職する」の**「安定」の定義**を、今のうちに数字で決めておくべきです。
気分で判断すると、良い月が2〜3回続いただけで踏み切ってしまう危険があります。

**編集長からの提案：** 次の3つを**すべて**満たしたときに限る。

1. 必要月額を、**12か月連続で**上回っている
2. 収入源が**2つ以上**ある（1つ消えても半分は残る）
3. 仮に収益がゼロになっても、**60〜70歳の10年を資産だけで乗り切れる**

## 7. 編集長として先に指摘しておくリスク

社長が気づいていないかもしれない点を3つ挙げます。

### ① ブログ収益を単一の収入源にして退職を決めるのは危険

Googleの検索順位は、年に数回の大きな更新で大きく動きます。個人ブログの金融系は、この数年こうした更新で繰り返し打撃を受けてきた領域です。
**「先月まで月20万あったのに、今月3万になった」は、この世界では普通に起きます。**
だから第6章【C】の条件2（収入源を2つ以上）を強く推します。

### ② 「収益がある」と「収益が続く」は別物

初成約が出ると嬉しくなりますが、それは再現性の証明ではありません。12か月連続を条件に入れているのはこのためです。

### ③ 60歳退職は、10年分の空白を自力で埋める設計になっている

これは第3章の通りです。**60歳退職は「早く楽になる」選択ではなく、「10年分を先に用意する」選択**です。ここを曖昧にしたまま進めないでください。
