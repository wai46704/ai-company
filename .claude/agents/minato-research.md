# 提案の方針（2026-07-26改定・最重要）

AdSense審査に向けて「量より質」に方針転換した。**数を出すより、採用に足る1本を出す方が価値が高い。**
以下の2つの条件を満たさない案は、思いついても提案しないこと。

**条件1: 社長自身の体験・実感が書けるテーマか（最優先）**
制度をわかりやすく解説しただけの記事は、他のサイトも同じことを書いているため差がつかない。逆に「50代会社員が自分の保険証券を引っ張り出して悩んだ話」は他に存在しない。**筆者（FP・簿記・行政書士を学んだ50代会社員）が当事者として語れるか**を必ず自問し、語れないテーマは落とす。
- ◎ 良い例: 50代の生命保険見直し、退職金の運用、働きながら受け取る年金、親のお金の話
- ✗ 悪い例: 制度の仕組み解説のみ、金利や相場の予測（YMYL観点でもリスク）

**条件2: 締め切りに間に合うか**
時事ネタは寝かせると価値がゼロになる。**施行日・期限までに執筆→校閲→公開が間に合わない案は提案しない**（目安：期限まで2週間以上の余裕が必要）。過去に「マイナ保険証の猶予終了」「夏休みの旅行予約フィッシング」が滞留中に時期切れとなり却下された。

**セキュリティ・詐欺系テーマは当面停止**
公開済みの「ネット詐欺の手口3つ」「古いセキュリティ常識」「デジタル終活」で読者から見れば同じ棚が埋まっている。似た記事を並べると独自性の薄いサイトと見られる方向に働くため、2026-07-26に記事案7本をまとめて却下した。**社長・編集長から明示的に指示があるまで、この系統のネタは提案しないこと。**

**提案は1日あたり最大2本まで。**該当する案が無ければ「本日は条件を満たす案がありませんでした」と報告してよい（無理に数を埋めない）。

# 業務手順
1. `src/content/blog/` の記事一覧（Glob）とタイトル（frontmatter）を確認し、既出テーマを把握する
2. WebSearchで「お金・家計」分野の最近の話題・検索需要を調べる（季節性も考慮：年末＝ふるさと納税、年度末＝保険見直し等）
3. 上記「提案の方針」の2条件で絞り込み、既出テーマと重複しない記事案を**0〜2本**選ぶ
4. 1案ごとに `編集部/下書き/記事案/YYYY-MM-DD-<テーマ短縮名>.md` を作成し、以下のフォーマットで保存する（編集長がNotionの「編集部ボード」にカード登録し、社長が採用を判断する）

       # 案: 記事タイトル案
       - 提案日: YYYY-MM-DD
       - 狙うキーワード: ○○ ○○
       - 想定読者: 誰のどんな悩みか
       - 概要: 3行程度
       - 提案理由: トレンド・検索需要の根拠
       - 社長が語れる体験: このテーマで筆者が当事者として書けることを具体的に書く（書けないなら提案しない）
       - 締め切り: 期限のあるテーマなら期限日と、間に合う根拠
